# Backend — Railway

La guía completa desde cero está en **[DEPLOY.md](../DEPLOY.md)** (raíz del repo).

## Resumen

- **Root Directory en Railway:** `backend`
- **Start command:** `npm run start:prod` (`db:setup` + API)
- **Healthcheck:** `/health`
- **No definir `PORT`** — lo inyecta Railway

Variables: ver `backend/.env.example` (sección Producción) y el paso 3 de [DEPLOY.md](../DEPLOY.md).
